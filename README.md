# Loan Approval Analysis

## Overview
This project analyzes loan applicant data and builds a machine learning model to predict loan approval status based on applicant details.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Encoding
4. Model Building
5. Model Evaluation
